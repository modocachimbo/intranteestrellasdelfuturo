# Intranet · IEP Las Estrellas del Futuro

Prototipo visual (HTML estático) de la nueva intranet. Abre `index.html` en el navegador.

| Página | Qué muestra |
|---|---|
| `index.html` | Ingreso (login) con selección de rol. "Ingresar" lleva al panel. |
| `panel.html` | Panel del docente: indicadores, mis cursos, agenda de hoy, comunicados. |
| `curso.html` | Aula virtual del curso (pestañas: Tablero, Cronología, Clases en vivo, Tareas, Exámenes, Material, Calificaciones, Asistencia, Foro). |
| `notas.html` | Registro de notas por competencias (AD · A · B · C) con conclusión descriptiva. |
| `movil.html` | Vista para celular del docente. |

El menú lateral enlaza Inicio, Mis cursos y Registro de notas. Los datos son de ejemplo.

Para verlo en línea: Settings → Pages → Branch `main` / carpeta raíz, y GitHub Pages lo publica.
